# Portofolio Akhmad Zakiya Alfarisi

Portofolio pribadi Veri yang menampilkan profil, proyek, dan latihan pemrograman.

Situs: https://akhmad-zakiya-alfarisiportofolio.vercel.app/

## Fitur

- Beranda profil dengan avatar GitHub Veri
- Halaman proyek dan formulir kontak
- Halaman Kantin Sekolah
- Latihan kalkulator nilai dan logika JavaScript di Console browser
- Tata letak responsif

## Teknologi

HTML5, CSS3, JavaScript, GitHub, dan Vercel.
